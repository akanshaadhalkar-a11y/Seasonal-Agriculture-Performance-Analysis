# Seasnal Agriculture Performance Analysis

## Project Description
- Analyzed agricultural performance across different crops and seasons.
- Studied environmental conditions, irrigation, production and economic factors.
- Performed data cleaning, statistical analysis and visualization.
- Identified patterns and trends to support better agricultural planning.

## Dataset
- 4,000 records
- 28 variables
- Contains crop, season, environmental, irrigation, production and economic data.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data cleaning
- Missing value handling
- Duplicate checking
- Statistical analysis
- Outlier analysis
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Correlation analysis
- Seasonal comparison
- Crop-wise analysis
- Irrigation efficiency analysis

## Key Results
- Sugarcane showed the highest average yield.
- Kharif showed the highest average yield and production.
- Kharif showed the highest average profit.
- Zaid showed negative average profit.
- Rainfall, temperature and soil moisture showed very weak linear relationships with yield.
